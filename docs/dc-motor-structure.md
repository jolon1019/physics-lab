# 直流电动机机械结构（直接供电 · 换向器可选）

> 设计目标：定子含带轴支撑构造；线圈为开口（非闭合）导体，其延长线平行于转子轴引至转轴末端的换向器；中间磁铁为外方内弧结构且保持非闭合（留有气隙）；线圈两端接轴上换向器 E/F 半环，电源经**静止电刷**接到换向器——导线随电刷固定、动画中不再断开。换向器可「开/关」切换：关=手动换向演示（摆到平衡位需手动翻转），开=自动连续旋转（真实直流电机行为）。
> 对应实验：`通电线圈在磁场中的转动`（教材 20.4）。

---

## 1. 结构总览

```
                      电源 (+)
                        │
                  ┌─────┴─────┐
   定子端盖/轴承座 │   电源    │   ← 静止电刷由此引出
   (含轴构造)      └─────┬─────┘
                        │ 导线 → 上电刷
   ┌── 轴承座 ──┐   ┌────┴────┐   换向器(E/F 铜半环, 随线圈转)
   │   ◯轴◯    │───┤ 开口线圈 │── 转子（绕 Z 轴；开态连续转 / 关态摆动）
   └── 轴承座 ──┘   └────┬────┘         ↑ 线圈两端引线接 E/F
                        │ 导线 → 下电刷
   N 外方内弧磁极 ──气隙──[线圈]──气隙── S 外方内弧磁极
   （两板分离，非闭合磁路）
```

- **定子（固定）**：两块外方内弧磁极（N 红 / S 蓝）+ 两端轴承座（支撑转子轴）+ 静止电刷 + 电源。
- **转子（旋转）**：开口线圈缠在转轴上，轴两端由定子轴承座支撑；线圈两端引线沿轴（Z）引到转轴末端的**换向器**（E/F 两铜半环，随线圈一起转），绝缘毂居中。
- **供电**：电源两极 → 静止电刷 → 换向器 E/F → 线圈两端。电刷不随线圈转，导线随之固定，**动画中不再断开**。

## 2. 部件与几何要点

### 2.1 定子
| 部件 | 形态 | 说明 |
|------|------|------|
| 磁极（外方内弧） | 极靴：**外缘正方块 + 内弧面**（内弧半径 `POLE_RIN=1.0` 包裹线圈、留气隙），沿 Z 拉伸 | N 在 −X 侧、S 在 +X 侧；内弧面凹向转子轴、正对线圈；两磁极间留**气隙**（非闭合磁路）。极弧半张角 `POLE_PHI=38°`（较旧版 60° 收敛，降低对展示的干扰） |
| 轴承座 ×2 | 固定支座（含轴孔） | 位于轴两端，承担「带轴的构造」——固定轴系、让转子绕轴转动。**标注文字已移除**（仅保留几何） |
| 静止电刷 ×2 | 石墨小块 | 位于换向器上/下，接触换向器外缘；导线由电刷引向电源（电刷不随线圈转） |

### 2.2 转子
| 部件 | 形态 | 说明 |
|------|------|------|
| 开口线圈 | 矩形导线，**不闭合**，留两引线端 | 有效边位于 ±X（磁极之间）；两端引线接换向器 E/F |
| 线圈延长线 | 两根直导线，**平行于轴（Z）** | 从线圈两端沿 +Z 伸到转轴末端的换向器（z = `COMM_Z=2.9`），作为 `coilGroup` 子物体（随线圈转，与换向器始终连着） |
| 换向器 | 轴上 E/F 两铜半环（留绝缘缝）+ 绝缘毂 | 位于转轴末端、电源一侧（z=`COMM_Z`），**随线圈绕 Z 轴转动**；E/F 分别接线圈两端 |
| 转子轴 | 圆柱 | 贯穿线圈，两端插入定子轴承座，末端承载换向器（长 `shaftLen=6.0`） |

### 2.3 供电与换向
- 电源置于换向器侧（z 取正、靠外，z=3.6），两输出端 → 静止电刷 → 换向器 E/F。
- 电流路径（关态/手动）：`电源+ → 上电刷 → 换向器 E 段 → 线圈端 A → 线圈 → 线圈端 B → 换向器 F 段 → 下电刷 → 电源−`。
- 开态（自动）：线圈转过平衡位（θ≈±90°）时，E/F 半环相对电刷换位 → 线圈内电流**自动翻转** → 力矩始终同向 → 连续旋转。

## 4. 物理原理

- **安培力**：有效边电流沿 Z，磁极提供径向磁场 B（沿 ±X），受力 `F = I·L·B`，方向由左手定则。
- **力矩与换向器开关**：
  - **关（手动换向演示）**：`τ(θ) = −K·cosθ·s`。`θ=0`（法线∥B）为稳定平衡位，线圈摆到此处即停；需在每次经过侧立位 `θ≈±90°`（按钮发光「现在点！」）时点击「⇄ 手动换向」翻转 `s`，力矩随之翻转、线圈持续旋转（手摇换向）。
  - **开（自动连续旋转）**：`τ(θ) = K·|cosθ|·s`。换向器在线圈越过平衡位时自动翻转电流，力矩**始终同向** → 线圈连续旋转（真实直流电机行为）。
- 物理本质一致：**换向器 = 在恰当时刻自动翻转电流的装置**；手动换向按钮即「人工充当换向器」。

## 5. 实现要点（`CoilRotateLab.vue` 改动清单）

1. **磁极外方内弧（非闭合，弧度收敛 + 间距拉开）**
   - `makePoleShoe()`：形状为「外缘正方块 + 内弧面」——内弧 `shape.absarc(0,0,POLE_RIN,−POLE_PHI,POLE_PHI,false)` 绕转子轴（凹向线圈、包裹线圈），两端直线连到外缘正方块四角闭合；`ExtrudeGeometry` 沿 Z 拉伸。
   - 旧版 `POLE_RIN=0.85 / POLE_ROUT=1.7 / POLE_PHI=60°` → 新版 `POLE_RIN=1.0 / POLE_ROUT=1.9 / POLE_PHI=38°`：极弧更收敛（降低展示干扰），磁极间距更大（气隙≈0.45，线圈仍居中）。
   - N 极 `mesh.rotation.y = Math.PI` 翻到 −X 侧；两块分离 = 非闭合磁路。

2. **整体抬高 3D 平面**
   - 所有几何加入 `root = new THREE.Group()`，`root.position.y = ROOT_Y = 0.9`；相机与 `controls.target` 相应上移（`target.y=0.3`），确保动画中平面始终可见、不被遮挡。

3. **移除轴承座标注文字**
   - 删除 `makeLabel('定子轴承座', ...)` 及其 `scene.add(lab)`；保留轴承座几何（Box + 轴孔）。

4. **换向器 + 静止电刷（随线圈转 / 静止引出，导线不断开）**
   - 换向器：`commE`/`commF` 两个 `CylinderGeometry` 半环（`thetaStart/thetaLength` 半圈 + 绝缘缝 `commGap`），`rotation.x=π/2` 使轴沿 Z；置于 `(0,0,COMM_Z)`，作为 `coilGroup` 子物体（随线圈转）。
   - 线圈延长线改引到 `COMM_Z` 并短接到 E/F 半环（`stubA/stubB`）；因同属 `coilGroup`，旋转时始终连着。
   - 静止电刷：`brushPos/brushNeg` 两个 Box，固定在换向器上/下，加入 `root`（不随线圈转）；电源导线改接电刷，导线随电刷固定 → 动画中不再断开。

5. **换向器 开/关 开关**
   - 新增 `commutatorOn` ref（默认关）+ 「换向器：关/开」按钮（`toggleCommutator`）。
   - 关态：显示「⇄ 手动换向」按钮 + 手动提示横幅；开态：隐藏手动按钮、显示「自动换向」提示横幅，并提供「↺ 反向旋转」按钮翻转整体转向。

6. **物理分支**
   - `animate()`：`commutatorOn` 真 → `alpha = K·|cosθ|·base`（连续旋转，轻阻尼）；假 → `alpha = −K·cosθ·base`（摆动，需手动换向）。
   - `liveState` / `liveNearFlip`：开态显示「自动换向·连续旋转」、不发光；关态保留侧立位发光提示。

7. **文案更新**
   - 公式面板标题「直流电动机结构（直接供电 · 换向器可选）」；右侧结构要点卡、操作要点、SVG 示意图同步（含换向器+电刷示意）；移除「去掉换向器」「无滑环」旧表述。

## 6. 与教材对应

- 本结构 = 教材图 20.4 的「换向器可选」版本：
  - **关**：无自动换向，线圈受恒定电流摆到平衡位静止；手动点「⇄ 手动换向」（θ≈±90° 发光提示）可使其持续旋转（手摇换向演示）。
  - **开**：接入换向器，线圈越过平衡位电流自动翻转 → 连续旋转（真实直流电机行为），直观说明「换向器是连续转动的必要条件」。
- 切换「换向器 开/关」即可对比两种运动，凸显换向器的作用。
