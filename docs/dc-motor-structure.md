# 通电线圈在磁场中转动（开口线圈 · 简化演示）

> 设计目标：定子含带轴支撑构造；线圈为开口（非闭合）导体，置于两块外方内弧磁极（N/S）之间；**已移除外接电源、静止电刷与轴上换向器**——改为用「⚡ 通电 / ⏻ 断电」按钮直接控制电流通断，配合「⇄ 手动换向」演示手摇换向。线圈宽度与磁极一致、磁极高度已增大，便于观察。
> 对应实验：`通电线圈在磁场中的转动`（教材 20.4）。

---

## 1. 结构总览

```
   ┌── 轴承座 ──┐                    ┌── 轴承座 ──┐
   │   ◯轴◯    │── 转子轴 ───────────│   ◯轴◯    │   转子轴沿 Z
   └── 轴承座 ──┘                    └── 轴承座 ──┘
                      开口线圈（绕 Z 轴；通电后摆向平衡位）
   N 外方内弧磁极 ──气隙──[线圈]──气隙── S 外方内弧磁极
   （两板分离，非闭合磁路；磁极高、线圈宽与磁极一致）
```

- **定子（固定）**：两块外方内弧磁极（N 红 / S 蓝）+ 两端轴承座（支撑转子轴）。**无电源、无电刷、无换向器**。
- **转子（旋转）**：开口线圈缠在转轴上，轴两端由定子轴承座支撑；绕 Z 轴转动。
- **供电方式**：点击「⚡ 通电」即视为线圈两端接通电源、有恒定电流；「⏻ 断电」断开。不再有任何外部导线/电刷/换向器几何。

## 2. 部件与几何要点

### 2.1 定子
| 部件 | 形态 | 说明 |
|------|------|------|
| 磁极（外方内弧） | 极靴：**外缘正方块 + 内弧面**（内弧半径 `POLE_RIN=1.0` 包裹线圈、留气隙），沿 Z 拉伸 | N 在 −X 侧、S 在 +X 侧；内弧面凹向转子轴、正对线圈；两磁极间留**气隙**（非闭合磁路）。极弧半张角 `POLE_PHI=46°`（较旧版 38° 增大 → 磁极更高、更挺拔），径向厚度 `MAG_W=0.95`、半高 `MAG_H=0.95`（较旧版增大 → 磁极更高） |
| 轴承座 ×2 | 固定支座（含轴孔） | 位于轴两端（z=±3.5），承担带轴构造——固定轴系、让转子绕轴转动。标注文字已移除（仅保留几何） |

### 2.2 转子
| 部件 | 形态 | 说明 |
|------|------|------|
| 开口线圈 | 矩形导线（X 宽 = `2W=0.95`，Z 宽 = `2D=2.4`），**不闭合** | 有效边位于 ±X（磁极之间）；**线圈 X 宽 = 磁极径向厚度 `MAG_W`，线圈 Z 宽 = 磁极拉伸深度 `POLE_DEPTH`，二者一致**，线圈正好填满磁极面 |
| 转子轴 | 圆柱（半径 `shaftR=0.14`，长 `shaftLen=10.0`） | 贯穿线圈，两端插入定子轴承座 |

### 2.3 供电与换向（简化）
- 无外部电源/电刷/换向器：`togglePower()` 用 `playing` 标志直接模拟通电/断电；通电时电流箭头（iL/iR）与受力箭头（fLeft/fRight）可见、电子流动，断电时隐藏。
- 电流方向由 `reverseCurrent` 控制；点「⇄ 手动换向」即翻转 `reverseCurrent`（= 手摇换向）。

## 4. 物理原理

- **安培力**：有效边电流沿 Z，磁极提供径向磁场 B（沿 ±X），受力 `F = I·L·B`，方向由左手定则。
- **力矩（无换向器）**：`τ(θ) = −K·cosθ·s`。`θ=0`（法线∥B）为稳定平衡位，线圈摆到此处即停；需在每次经过侧立位 `θ≈±90°`（按钮发光「现在点！」）时点击「⇄ 手动换向」翻转 `s`，力矩随之翻转、线圈持续旋转（手摇换向）。
- 物理本质：**换向器 = 在恰当时刻自动翻转电流的装置**；本演示移除换向器后，「⇄ 手动换向」按钮即「人工充当换向器」。

## 5. 实现要点（`CoilRotateLab.vue` 改动清单）

1. **移除电源 / 电刷 / 换向器**
   - 删除外接电源 Box、+ / − 端子、开关（底座/拨杆/触点）、静止电刷、轴上换向器 E/F 半环与绝缘毂、线圈延长线及所有 `makeWire` 导线。
   - 删除 `commutatorOn` 状态与「换向器 开/关」按钮、`toggleCommutator`、`auto-hint` 横幅。

2. **播放按钮 → 通电/断电**
   - 原「▶ 播放 / ⏸ 暂停」改为「⚡ 通电 / ⏻ 断电」（`togglePower`，切换 `playing` 并调用 `setEnergized` 显隐电流/受力箭头）。

3. **线圈宽度与磁极一致 + 磁极增高**
   - 磁极参数新增 `MAG_W`（径向厚）、`MAG_H`（半高）、`POLE_DEPTH`（Z 拉伸）；`makePoleShoe()` 用 `MAG_W/MAG_H` 画外缘正方块，`POLE_PHI` 由 38° 增至 46°（更高）。
   - 线圈 `W=0.475`（`2W=0.95=MAG_W`）、`D=1.2`（`2D=2.4=POLE_DEPTH`），使线圈宽（X、Z）均与磁极一致、填满磁极面。

4. **物理分支简化**
   - `animate()` 仅保留无换向器分支：`alpha = −K·cosθ·base`（摆动，阻尼 0.992，趋向平衡位）。
   - 通电时电流/受力箭头可见、电子流动；断电时隐藏、电子静止。

5. **文案更新**
   - 公式面板标题「通电线圈在磁场中转动（开口线圈）」；结构要点卡第三张改为「通电：I → 受力 F=BIL」示意图；保留开口线圈卡与磁极卡；操作要点改为「通电 + 手动换向」流程。

## 6. 与教材对应

- 本结构 = 教材 20.4「通电线圈在磁场中转动」的开口线圈演示：
  - 通电：线圈受恒定电流只摆到平衡位（θ≈0）即停。
  - 手动点「⇄ 手动换向」（θ≈±90° 发光提示）翻转电流 → 持续旋转（手摇换向演示），直观说明「换向器是连续转动的必要条件」。
- 移除外部电源/电刷/换向器，使结构更简洁、聚焦「磁场中通电导体受力转动」这一核心现象。
