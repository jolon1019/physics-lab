# 直流电动机机械结构（含换向器 · 无外接电源/电刷/轴承座）

> 设计目标：线圈为开口（非闭合）导体，其延长线平行于转子轴引至转轴末端的**换向器**（E/F 半环）；中间磁铁为外方内弧结构且保持非闭合（留有气隙）；线圈宽度与磁极宽度一致。本版**移除外接电源盒、静止电刷、两侧轴承座**，仅保留换向器作为转子结构件展示；用「⚡ 通电 / ⏻ 断电」按钮概念性供电，并以「⇄ 手动换向」演示换向器自动完成的「过平衡位翻转电流 → 连续旋转」工作（手摇换向）。
> 对应实验：`通电线圈在磁场中的转动`（教材 20.4）。

---

## 1. 结构总览

```
                   ┌── 转子轴（沿 Z）──┐
                   │                  │
   换向器(E/F 铜半环) 开口线圈(绕 Z 轴摆动/手摇换向)   ← 线圈两端引线接 E/F
   (随线圈转·结构件)  └──────┬──────┘         ↑ 引线平行轴 Z 接换向器
                            │
   N 外方内弧磁极 ──气隙──[ 线圈 ]──气隙── S 外方内弧磁极
   （两板分离，非闭合磁路；线圈 X/Z 宽与磁极一致）
```

- **定子（固定）**：两块外方内弧磁极（N 红 / S 蓝），分离 = 非闭合磁路。本版不含轴承座、不含电刷、不含外接电源盒。
- **转子（旋转）**：开口线圈缠在转轴上；线圈两端引线沿轴（Z）引到转轴末端的**换向器**（E/F 两铜半环，随线圈一起转），绝缘毂居中。
- **供电（概念化）**：「⚡ 通电」按钮使线圈通电 → 受磁场力开始摆动；「⇄ 手动换向」在每次过侧立位翻转电流方向，维持连续旋转（即真实电机中换向器+电刷自动完成的工作）。

## 2. 部件与几何要点

### 2.1 定子（磁极）
| 部件 | 形态 | 说明 |
|------|------|------|
| 磁极（外方内弧） | 极靴：**外缘正方块 + 内弧面**（内弧半径 `POLE_RIN=1.5` 包裹线圈、留气隙），沿 Z 拉伸 `POLE_DEPTH=1.2` | N 在 −X 侧、S 在 +X 侧；内弧面凹向转子轴、正对线圈；两磁极间留**气隙**（非闭合磁路）。极弧半张角 `POLE_PHI=38°`（较旧版 60° 收敛，降低对展示的干扰） |
| 磁极 X 向宽度 | `MAG_W = POLE_ROUT − POLE_RIN·cos(POLE_PHI) ≈ 2.318` | 外缘(3.5) − 内弧端(1.182)；线圈 X 宽 `2W = MAG_W` 与之对齐（**横置锤型：X 宽 2.32 > Z 厚 1.2**） |
| 磁极 Z 向厚度 | `POLE_DEPTH = 1.2` | 线圈 Z 宽 `2D = POLE_DEPTH` 与之对齐（已减半，让线圈横置） |

### 2.2 转子
| 部件 | 形态 | 说明 |
|------|------|------|
| 开口线圈 | 矩形导线，**不闭合**，留两引线端 | X 宽 `2W≈2.318`（=磁极 X 宽）、Z 厚 `2D=1.2`（=磁极 Z 厚）；**X 宽 2.32 > Z 厚 1.2，呈横置锤型**；有效边位于 ±X（磁极之间） |
| 线圈延长线 | 两根直导线，**平行于轴（Z）** | 从线圈两端沿 +Z 伸到转轴末端的换向器（z = `COMM_Z=3.8`），作为 `coilGroup` 子物体（随线圈转，与换向器始终连着） |
| 换向器 | 轴上 E/F 两铜半环（留绝缘缝）+ 绝缘毂（半径 0.16，包住轴） | 位于 `COMM_Z=3.8`，**随线圈绕 Z 轴转动**；本版不含电刷/外接电源，仅作转子结构件展示，并标注「换向器」 |
| 转子轴 | 圆柱 | 贯穿线圈，长 `shaftLen=10.0`（z: −5.0~+5.0），末端伸到换向器处 |

### 2.3 供电与换向（概念化）
- 本版无外接电源盒、无静止电刷、无轴承座；「⚡ 通电」按钮概念性供电、「⇄ 手动换向」概念性翻转电流。
- 线圈两端引线接换向器 E/F（转子内部接线，随线圈转，动画中始终连着）。
- 电流路径（手动换向演示）：`通电 → 线圈端 A → 线圈 → 线圈端 B → 换向器 E/F → 回到线圈`（闭合回路示意）；每次过侧立位（θ≈±90°）点「⇄ 手动换向」翻转电流方向 → 力矩翻转 → 持续旋转（手摇换向，即真实电机中换向器+电刷自动完成的工作）。

## 4. 物理原理

- **安培力**：有效边电流沿 Z，磁极提供径向磁场 B（沿 ±X），受力 `F = I·L·B`，方向由左手定则。
- **力矩与手动换向**：
  - `τ(θ) = −K·cosθ·s`。`θ=0`（法线∥B）为稳定平衡位，线圈摆到此处即停；需在每次经过侧立位 `θ≈±90°`（按钮发光「现在点！」）时点击「⇄ 手动换向」翻转 `s`，力矩随之翻转、线圈持续旋转（手摇换向）。
  - 物理本质：换向器 = 在恰当时刻自动翻转电流的装置；本版用「手动换向」按钮人工充当换向器（因未接电刷/外接电源，无法自动换向，故以手摇演示其原理）。

## 5. 实现要点（`CoilRotateLab.vue` 改动清单）

1. **磁极外方内弧（非闭合，弧度收敛 + 间距拉开 + 整体外推+变薄）**
   - `makePoleShoe()`：形状为「外缘正方块 + 内弧面」——内弧 `shape.absarc(0,0,POLE_RIN,−POLE_PHI,POLE_PHI,false)` 绕转子轴（凹向线圈、包裹线圈），两端直线连到外缘正方块四角闭合；`ExtrudeGeometry` 沿 Z 拉伸（厚度 `POLE_DEPTH`）。
   - `POLE_RIN=1.5 / POLE_ROUT=3.5 / POLE_PHI=38° / POLE_DEPTH=1.2`：极弧更收敛（降低展示干扰），磁极整体外推+变薄让线圈 X 宽(2.32) > Z 厚(1.2)，呈横置锤型（线圈如同横放的锤头，长轴沿 X；轴如同锤柄沿 Z）。

2. **线圈宽度与磁极一致**
   - 新增 `MAG_W = POLE_ROUT − POLE_RIN·cos(POLE_PHI)`（磁极 X 向宽度）、`POLE_DEPTH`（磁极 Z 厚，模块级常量供 `makePoleShoe` 使用）。
   - `W = MAG_W/2`（线圈 X 半宽 → `2W = MAG_W` 与磁极 X 宽一致）、`D = POLE_DEPTH/2`（线圈 Z 半深 → `2D = POLE_DEPTH` 与磁极 Z 厚一致）。

3. **移除外接电源盒、静止电刷、两侧轴承座**
   - 删除 `supply`(电源盒)/`termPos`/`termNeg`(端子)/`swBase`+`postL/R`+`leverBar`(开关)/`wPos`/`wNeg`(电源→电刷导线)/`brushPos`/`brushNeg`/`labBrush`(电刷)/轴承座 `for(const sz of [±3.5])` 循环（含 Box + 轴孔）。
   - 仅保留换向器 `commE/commF`+绝缘毂+`labE/labF` 及其「换向器」标签（转子结构件展示）。

4. **交互简化为「通电 + 手动换向」**
   - 「▶ 播放/⏸ 暂停」→「⚡ 通电/⏻ 断电」（`togglePower` 切换 `playing`）。
   - 移除「换向器 开/关」开关与 `commutatorOn`：无电刷无法自动换向，故仅保留「⇄ 手动换向」（`reverseCurrent` 翻转）维持旋转；`btn-flip` 在 `liveNearFlip`（通电且 θ≈±90°）时发光「现在点！」。
   - 物理仅保留手动分支 `alpha = −K·cosθ·base`（阻尼 0.992，最终静止于平衡位）；通电时电子流流动、断电时静止。

5. **文案更新**
   - 公式面板标题「直流电动机结构（含换向器 · 无外接电源/电刷）」；右侧结构要点第三张卡改为「换向器（转子结构件）E/F 半环」；操作要点、SVG 示意图同步（无电刷/电源/轴承座）；移除「换向器 开/关」对比表述。

## 6. 与教材对应

- 本结构 = 教材图 20.4 的「换向器结构件展示」版本（无外电路）：
  - 「⚡ 通电」：线圈受恒定电流摆到平衡位（θ≈0）静止。
  - 「⇄ 手动换向」：在 θ≈±90°（按钮发光）时点击翻转电流，力矩翻转 → 持续旋转（手摇换向，直观演示换向器「过平衡位自动翻转电流」的作用）。
- 换向器作为轴上 E/F 两铜半环结构件保留展示；真实电机中电源经静止电刷接到换向器，过平衡位自动翻转电流 → 连续旋转。
