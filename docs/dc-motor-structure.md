# 直流电动机机械结构（直接供电 · 无滑环）

> 设计目标：定子含带轴支撑构造；线圈为开口（非闭合）导体，其延长线平行于转子轴引至电源接线处；中间磁铁为四边形结构且保持非闭合（留有气隙）；取消滑环/电刷，改由电源直接连接线圈两端引线供电。
> 对应实验：`通电线圈在磁场中的转动`（教材 20.4）。本结构刻意去掉换向器，用于演示「无换向器 → 恒定电流下线圈只能摆到平衡位、不能连续转动」，从而反衬换向器的必要性。**但**在每次经过侧立位（θ≈±90°）时手动点击「⇄ 手动换向」翻转电流方向，即可像手摇换向器一样让线圈持续旋转。

---

## 1. 结构总览

```
                      电源 (+)
                        │
                  ┌─────┴─────┐
   定子端盖/轴承座 │   电源    │   ← 直接供电，无滑环
   (含轴构造)      └─────┬─────┘
                        │ 线圈延长线①（平行轴 Z）
   ┌── 轴承座 ──┐   ┌────┴────┐
   │   ◯轴◯    │───┤ 开口线圈 │── 转子（绕 Z 轴，平衡位附近摆动）
   └── 轴承座 ──┘   └────┬────┘
                        │ 线圈延长线②（平行轴 Z）
   N 四边形磁极 ──气隙──[线圈]──气隙── S 四边形磁极
   （两板分离，非闭合磁路）
```

- **定子（固定）**：两块四边形磁极（N 红 / S 蓝）+ 两端轴承座（支撑转子轴）。
- **转子（旋转）**：开口线圈缠在转轴上，轴两端由定子轴承座支撑；线圈两端引线沿轴（Z）方向平行伸出到电源接线柱。
- **供电**：电源两极用导线直接连到线圈两条延长线的末端，省去滑环与电刷。

## 2. 部件与几何要点

### 2.1 定子
| 部件 | 形态 | 说明 |
|------|------|------|
| 四边形磁极 | 梯形/矩形极靴板（沿 Z 拉伸） | N 在 −X 侧、S 在 +X 侧，极面朝向线圈；两板之间留**气隙**（非闭合磁路，无轭部连接） |
| 轴承座 ×2 | 固定支座（含轴孔） | 位于轴两端，承担「带轴的构造」——固定轴系、让转子绕轴摆动 |

### 2.2 转子
| 部件 | 形态 | 说明 |
|------|------|------|
| 开口线圈 | 矩形导线，**不闭合**，留两引线端 | 有效边位于 ±X（磁极之间）；两端引线不接回，而是向外引出 |
| 线圈延长线 | 两根直导线，**平行于轴（Z）** | 从线圈两端沿 +Z 伸出到电源接线处（z = `commZ`） |
| 转子轴 | 圆柱 | 贯穿线圈，两端插入定子轴承座 |

### 2.3 供电
- 电源置于换向器侧（z 取正、靠外），两输出端用导线直连线圈延长线末端。
- 电流路径：`电源+ → 导线 → 线圈延长线① → 线圈有效边 → 线圈延长线② → 导线 → 电源−`。

## 4. 物理原理

- **安培力**：有效边电流沿 Z，磁极提供径向磁场 B（沿 ±X），受力 `F = I·L·B`，方向由左手定则。
- **力矩**：`τ(θ) = −K·cosθ·s`
  - `θ`：线圈法线与磁极轴（X）夹角；`s`：电流方向符号（正向/反向）。
  - `θ=0`（法线∥B，线圈平面⊥B）：`cosθ=1`，力矩最大？——注意此处 `τ` 形式取「使线圈转向平衡位」：`θ=0` 为**平衡位**（力矩为 0 且稳定），越过则反向 → 摆动收敛到 `θ=0`。
- **无换向器 ⇒ 恒定电流不能自动连续转**：电流方向恒定，线圈摆到平衡位即停（阻尼后静止）；点「反向电流」则摆向另一侧平衡位（θ=π）。
- **手动换向（手摇换向演示）**：在每次线圈经过侧立位 `θ≈±90°`（此处 `cosθ` 变号、本应是力矩反向点）时手动翻转电流方向 `s`，则 `τ` 始终沿当前旋转方向驱动 → 线圈可像被手摇换向器控制一样**持续旋转**。这正说明：换向器本质就是"在恰当时刻自动翻转电流"的装置。
- **对比**：保留换向器时 `τ = K·s·|cosθ|`（方向恒定）→ 连续转动。本设计特意去掉自动换向，正用于凸显这一差别，同时保留手动换向作为交互演示。

## 5. 实现要点（`CoilRotateLab.vue` 改动清单）

1. **磁极四边形化（非闭合）**
   - `makePoleShoe()`：将 `shape.absarc` 弧改为**四边形（梯形）**极靴（内边 ri 窄、外边 ro 宽，4 点直线连接）。
   - 保持 N（angleCenter=π）/ S（angleCenter=0）两块分离调用，中间留气隙 = 非闭合。

2. **线圈开口 + 平行引线**
   - `pts` 改为 4 点（去掉闭合末点），`TubeGeometry(curve, 80, 0.07, 10, false)`（closed=false）。
   - 新增两根引线：`makeWire` 从 `(±W/2, 0, D/2)` 沿 +Z 到 `(±W/2, 0, commZ)`，作为 `coilGroup` 子物体（随线圈摆动）。

3. **删除滑环/换向器/电刷**
   - 删 `commRings`/`slipRings`/`brushA`/`brushB`/`labelE`/`labelF`/`labelSlip` 创建与显隐。
   - 删 `toggleCommutator()`、`applyCommutatorVisual()` 中换向器分支；删 `commutator` ref。
   - UI：删「⇄ 换向器」按钮与 badge。

4. **定子轴承座（带轴构造）**
   - 新增两个固定支座（Box），位于轴两端（z≈±2.8），中心留轴孔视觉，标记「定子轴承座」。

5. **供电改为直连**
   - 电源导线终点由「电刷」改为「线圈延长线末端 `(±W/2, 0, commZ)`」；保留 `wireEnergized` 通电变色。

6. **物理去换向器分支**
   - `computeDrive()`：`return -K * Math.cos(angle) * base`（去掉 `|cos|` 与 commutator 判断）。
   - `currentDirSign()`：`return base`（恒方向）。
   - `reset()`：初始角给小偏角（如 0.6 rad）以便观察到摆向平衡位的过程。

7. **文案更新**
   - 说明：线圈为开口导体、两端延长线平行轴直连电源、无滑环；通电后摆到平衡位（演示为何需要换向器）。

## 6. 与教材对应

- 本结构 = 教材图 20.4 系列的「去掉换向器」版本：线圈在磁场中受恒定电流，**摆到平衡位静止**。
- 配合「⇄ 手动换向」按钮，在 θ≈±90°（按钮发光提示「现在点！」）时点击翻转电流，可演示：**手动换向 → 线圈持续旋转**（手摇换向）。
- 若要展示自动连续转动，需恢复换向器（铜半环 E/F + 电刷），即另设对比模式。
